# Research scope and initial gaps

This is a new project-local reading list, not an existing ARF paper corpus. No
downloaded paper assets or paper aggregator existed in this repository. Bibliography and
reading coverage are recorded in research_internet.md; full-text access is distinguished
from abstract-only access. The glite-arf research-internet process is adapted for source
selection and independent format validation; no private arf-evals implementation is
used.

## Gaps and Limitations

* G1: Is there credible frequency evidence for purchasing failures, especially Finland?
* G2: Which practical procurement decisions should hard cases require?
* G3: How can evaluation distinguish model competence from harness protection?
* G4: Is demand prediction currently supported by real kitchen history?
