It scores actions, not answers.

The score comes from the order, the signed mandate, API scope and audit trail left behind. A model saying “done” does not count if the gateway did something else.

Recorded mode replays, it doesn't re-evaluate.

The Nemotron option replays saved replies from an earlier model run against today's code. It does not test a new model or prompt.

A capture is not a stock reservation.

The official lane captures mock API prices and availability once. Subsequent tools and commit checks read that pinned snapshot, not fresh supplier stock. The synthetic lane runs separate safety scenarios.
